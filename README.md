Sekai Fanpage
A fan-made website about Project SEKAI: COLOURFUL STAGE!. This website provides an introduction to the game, its characters, music, Sekai worlds, events and character cards. 

Pages
 - Home, An introduction to Project SEKAI. 
 - The Game, Information about the game and how it works. 
 - Characters, An overview of the five groups and their members. 
 - Music, A selection of songs featured in the game. 
 - Sekai Worlds, Information about the different Sekai. 
 - Events, An introduction to events, character cards and personal favourites. 

Features
 - Navigation between six pages. 
 - Responsive layout for different screen sizes. 
 - Pastel colour scheme and custom styling. 
 - Character, song, event and card images. 
 - Mobile navigation menu. 

Files and Folders
 - .html files, The website pages. 
 - style.css, Website styling and layout. 
 - script.js, JavaScript functionality. 
 - images/, Images used throughout the website. 

How to View
Open the link: https://24106.github.io/project-sekai-fanpage/ on any web browser to access it.
